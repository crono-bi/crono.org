# Versiones Crono Metadata

## Versión actual

Crono Metadata es la capa semántica de la plataforma Crono. Permite definir el modelo de datos, relaciones, cálculos y reglas de negocio de forma centralizada.

## Requisitos del sistema

- Windows 10 o superior
- 4GB de RAM mínimo (8GB recomendado)
- 2GB de espacio en disco
- Acceso a las bases de datos de origen

## Información adicional

Crono Metadata está diseñado para administradores de datos y desarrolladores BI que necesitan crear y mantener el modelo semántico de la organización.
