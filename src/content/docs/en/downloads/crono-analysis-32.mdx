# Versiones Crono Analysis 32 bits

## Información

Esta versión de 32 bits es necesaria si no dispone de drivers de 64 bits para conectarse a sus orígenes de datos.

## Requisitos

- Windows 10 o superior (x86)
- 4GB de RAM mínimo
- 1GB de espacio en disco
