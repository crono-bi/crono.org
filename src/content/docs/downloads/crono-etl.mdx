# Versiones Crono ETL

## Versión actual

Crono ETL automatiza las cargas diarias de datos hacia el Data Warehouse. Diseñado para cargas que nunca fallan y ahorran horas de trabajo manual.

## Requisitos del sistema

- Windows 10 o superior / Windows Server 2016 o superior
- 4GB de RAM mínimo (8GB recomendado)
- 2GB de espacio en disco
- Acceso a las fuentes de datos y al Data Warehouse

## Información adicional

Crono ETL es la herramienta ideal para equipos de datos que necesitan automatizar procesos de extracción, transformación y carga de datos de forma fiable y programada.
