# Versiones Crono Server

## Versión actual

Crono Server es la infraestructura de servidor de la plataforma Crono. Proporciona los servicios necesarios para ejecutar aplicaciones Crono en entornos corporativos.

## Requisitos del sistema

- Windows Server 2016 o superior
- 8GB de RAM mínimo (16GB recomendado)
- 10GB de espacio en disco
- IIS (Internet Information Services)

## Información adicional

Crono Server está diseñado para administradores de sistemas que necesitan desplegar y mantener la infraestructura Crono en entornos empresariales.
