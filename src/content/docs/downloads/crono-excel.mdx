# Versiones Crono Excel

## Información

Crono Excel permite crear informes y análisis de datos directamente desde Microsoft Excel, conectándose a la capa semántica de Crono Metadata.

## Requisitos

- Microsoft Excel 2016 o superior
- [.NET Framework 4.7](https://dotnet.microsoft.com/download/dotnet-framework) o superior
- Windows 10 o superior
